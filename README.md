# 🛒 Dokan Shop

A simple and modern e-commerce product showcase website. The site allows users to browse items through dedicated category pages and view individual product details easily.

---

## ✨ Features

- 🗂️ Dedicated category pages (Men, Women, Kids, Accessories).
- 📦 Detailed product views.

---

## 🛠️ Built With

- **HTML5**: For semantic structure and web pages.
- **CSS3**: For custom styling and visual layout.
- **Bootstrap**: For responsive grid systems and pre-styled UI components.
